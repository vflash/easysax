# 0.6.0

* изменения api. теперь "объект атрибутов" передается в обработчик событий по умолчанию.
* добавлен флаг `lazy` в настройках парсера. При `lazy: true` в обработчик передается функция для получения "объекта атрибутов" по требованию (как было ранее).
